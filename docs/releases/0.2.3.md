### What's new

- **One Add vault button.** Create a vault or connect one on a server from the same dialog (Ctrl+N works too). The
  vault you opened last leads the front page, with its graph, what it holds and the notes that arrived since your
  last visit.
- **A calmer start.** Getting started shows where you are and the one next step instead of a long checklist, and the
  setup guide keeps the focus on one step at a time.
- **Faster, gentler file conversion.** A document is converted once instead of twice (a 48-page paper in about half
  the time), on half your processor cores at background priority, so the computer stays usable while it works.
  Remove and Cancel stop a conversion for real, and files up to 100 MB are accepted.
- **A simpler intake.** Each file shows one plain line — Reading, Ready, Added — and a file already in the vault is
  held before it is read again.
- **Processing starts sooner.** A new source starts within about 15 seconds of being added instead of up to a
  minute, and with a hosted model up to three sources are processed at once. Changing the model while sources
  process no longer fails the run in progress.
- **Orphaned notes get a second pass.** A new *Reweave notes* workflow in every vault finds notes that processing
  left on their own — no links, in no map — and connects and places them once the vault has grown around them. It
  also picks up notes that closing the app left half-processed.
- **Backups as one file.** Settings › Backup & restore saves your vaults as one `.kvbackup` file that you can take to
  another computer and restore there. Keys are never included.
- **Safer storage.** Built on Powerhouse 6.2.3-dev.52: every save is written to disk before it counts, so a power cut
  no longer risks a vault, and a full disk stops the engine cleanly instead of hanging it.
- **After a crash**, processing comes back within about a minute, and the status says *Processing starts in a
  moment* instead of showing an error.
- **Workflow Studio** is the latest version: the block picker groups blocks by piece, and **+**, Back and Forward and
  Delete all work inside the app.
- **Remote vaults on an older server** say so plainly instead of showing a raw error.
