### What's new

- **Ask what changed.** "What changed in the Powerhouse stack since September?" gets a short account: how much the
  subject grew and in which areas, the claims that are new, and the ones that changed, with what the vault said before
  beside what it says now, each with its source. A follow-up such as "and in authorisation?" keeps the same period. An
  answer about offline or unavailable things in your vault's subject is no longer mistaken for the vault being down.
- **Notes, by where they came from.** The Notes page shows each note beside the source it came from, chapter by
  chapter, with the source's kind, date and topics in the margin. It can also group them by topic, or list them all
  (most linked, newest, or A to Z). Each card shows the whole claim, and a note opens in place.
- **Workflows follow updates.** When an update brings new versions of the steps the app ships, every workflow moves
  to them when the app starts, with nothing to click, so Workflow Studio no longer marks steps as pinned to a version
  that is gone. A workflow with changes you have not published in Studio is left as it is.
- **Back and Forward in Workflow Studio** step between the workflows you opened. Back used to close the open
  workflow, and Forward went nowhere.
- **Your pipelines keep their keys across this update.** The workflow engine now gives each saved key only to the
  connection that uses it, and the keys an earlier version saved are handed to their connections when the app starts,
  so pipelines, starter workflows and Studio connections carry on.
- **Big vaults answer straight after a start.** The engine now keeps its database statistics: on a 930 MB vault, the
  first change after a start held up every read and write for about six minutes; it now takes six seconds.
- **A lighter engine.** It no longer carries browser wallet libraries it never uses: on Windows, 38,774 files instead
  of 176,693, and 423 MB on disk instead of 818. When the first start of a version unpacks it, the window shows the
  progress, and the previous version is removed only once the app is running.
- **On macOS, an update goes to Applications.** Opened from its disk image or from Downloads, the new version offers
  to move itself into Applications before it opens your vaults, so the Dock never starts an older copy that would
  refuse them.
- **In a narrow window** the sidebar folds into a menu button, and the chat takes the full width.
- **The engine runs on Node 26,** the current long-term support line, and needs about a fifth less memory once it has
  started (about 1.0 GB instead of 1.3 GB, measured on a fresh vault). On Linux the `.deb` now installs `libatomic1`
  with it; the AppImage carries its own copy.
- **Built on Powerhouse 6.2.3-dev.90** and the vault package 1.0.54-dev.59, with Tauri 2.12.5 and a refreshed model
  catalog (110 OpenAI, Anthropic, Google and xAI models).
