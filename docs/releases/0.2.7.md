### What's new

- **Paste text opens on the text.** Paste text now opens a box to paste or type into, with a title, and the source is
  created with its text only when you press Add source; cancelling leaves nothing behind. It used to create an empty
  source first, which on the desktop could not be opened to paste into.
- **A document you create opens straight away.** A source, note or anything else added in the vault opens when you
  click it, without restarting the app. Before, the app listed a new document but did not open it.
- **The OpenRouter card shows what is left to do.** Once you are signed in, it links to your OpenRouter dashboard
  (credits, usage and keys) in place of Sign in with OpenRouter, and a saved key reads "Saved on this computer" beside
  Remove key instead of an empty field. Signing in is the way in; "or paste a key" opens the key field for someone who
  would rather paste one.
- **Built on** the vault package 1.0.54-dev.60.
