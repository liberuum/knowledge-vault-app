### What's new

- **A setup guide on first start.** Choose your AI, name your first vault, add your first sources (or the app's own guide, *How Knowledge Vault works*) and watch the vault fill up.
- **Continue with ChatGPT.** Use your ChatGPT Plus or Pro plan for the chat and the processing: one sign-in, no API key.
- **One AI model for the whole app.** In Settings › Models: a model on this computer, ChatGPT, OpenRouter (sign in, no key to paste) or an API key for OpenAI, Anthropic, Google Gemini, xAI or another service. The chat and the processing both use it, and your keys stay inside the app.
- **Models on this computer are found for you.** Ollama, LM Studio, llama.cpp, vLLM, Jan and others, on any port, with a hint for the model size your graphics card runs well.
- **Connect a remote vault by its address.** Paste the server's address (with or without `/graphql`, or a link to one of its vaults) and pick from the vaults it lets you read. Vaults on an open server connect without signing in.
- **Getting started.** A list on the front page, ticked as you go, until you close it. Settings › Getting started keeps it.
- **Processing picks up where it stopped.** A source cut off part-way resumes at the step it reached instead of starting over or getting stuck.
- **Fixes.** Several files dragged in at once on Linux all arrive; the vault's menu bar fits a narrow window; a fresh install starts with a clean slate. On Windows: the first start after an update shows the engine being prepared instead of an error, the graphics-card hint works without an NVIDIA card, finding local models works in any Windows language, and Settings › Conversion says when the PDF converter needs Microsoft's Visual C++ runtime.
